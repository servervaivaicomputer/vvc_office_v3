About

This system uses a split-architecture model: Netlify serves the public frontend while Render hosts the authenticated backend. Every protected page is independently verified server-side on each request.

How It Works

When you access a protected page, the backend verifies your JWT cookie on every request. No page content is ever served without a valid, server-verified session.

Security Stack

  • Bcrypt password hashing
  • JWT in HttpOnly cookies
  • Automatic account lockout
  • Rate limiting & security headers
  • Full audit logging
