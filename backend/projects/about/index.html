About This System

Security-first architecture for protected content delivery.

Architecture

This application uses a split-architecture approach: the frontend is hosted on Netlify for fast static delivery, while the backend runs on Render, handling all authentication, authorization, and protected content serving. MongoDB Atlas provides the persistent data layer.

Every request to a protected page is authenticated server-side using JWT tokens stored in HttpOnly, Secure cookies. No credentials or authorization logic is ever exposed to the client.

Security Features

  • ◆ Bcrypt password hashing with 12 salt rounds
  • ◆ JWT in HttpOnly + Secure + SameSite cookies
  • ◆ Automatic account lockout after 10 failed attempts
  • ◆ Per-device and per-IP tracking and blocking
  • ◆ Helmet security headers (CSP, HSTS, X-Frame, etc.)
  • ◆ Rate limiting on all endpoints
  • ◆ NoSQL injection sanitization
  • ◆ CORS restricted to frontend origin
  • ◆ Input validation and output sanitization
  • ◆ Full audit logging of every action

Stack

  • ▸ Runtime: Node.js + Express
  • ▸ Database: MongoDB Atlas (Mongoose ODM)
  • ▸ Frontend: Static HTML/CSS/JS on Netlify
  • ▸ Backend: Express on Render
  • ▸ Auth: JSON Web Tokens (JWT)
